# Reading Order

Generated by the benchmark's `accuracy/test_reading_order.py` — do not edit by hand.

**Date:** 2026-10-23
**Pipeline:** `extract_text` → `segment_elements` → `render_elements`, segmented at a 2000-token budget under a 5-page ceiling (`isaacus/kanon-2-tokenizer`) — the `configs/example.yaml` defaults.

**This is a behaviour baseline, not an accuracy score.** No fixture carries a human-annotated correct element ordering, so nothing here is measured against a reading-order reference. The per-segment deltas U3 asks for "where ground truth exists" are null today and become live once the ground-truth sidecars land (U6c). What the suite gates now is the invariant that holds without a reference: the renderer reorders nothing, so every segment's rendered `order` sequence is strictly ascending and a subsequence of its source element orders, and the segments' rendered orders concatenate — gapless, no overlap — into a strictly ascending run over the whole document.

**Scope.** The womblex-collection documents (PDF, DOCX) — the kinds the renderer's closed structural set covers (narrative, tables, forms). Spreadsheets are excluded: the renderer emits nothing for `sheet_cell` elements, which reach chunking through a synthetic-table projection rather than the reviewer renderer. The OCR image crops (FUNSD, IAM, DocLayNet) are single elements with no ordering to check.

The **Reordered** column is the count of segments whose rendered order departed from their source element order; it is `none` because the renderer is a pure projection over an ordered list, and the suite fails on any other value. **Rendered elements** is below **Elements** wherever a fixture carries kinds outside the closed set (images, page breaks, sheet cells), which contribute nothing and so hold no position in the output.

## Known limitations

1. **No reading-order ground truth** — there is no human-annotated correct ordering for any fixture, so this measures the renderer's fidelity to the extracted order, not the extracted order's fidelity to the page. Deltas against a corrected order await the ground-truth sidecars (U6c).
2. **Extraction reading order is upstream** — a multi-column page or an interleaved table mis-ordered by extraction shows here as the source order the renderer faithfully reproduces, not as a renderer fault. Attributing such an error needs the corrected order above.
