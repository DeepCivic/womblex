## Extraction Strategy Matrix

Doc-level types are a *summary attribute* of the orchestrator's per-page dispatch (`_apply_native_page` / `_apply_ocr_page`); per-page routing is what determines actual behaviour. Non-PDFs route via `get_extractor()`.

| Document Type | Path | Per-page operations |
|---------------|------|---------------------|
| NATIVE_NARRATIVE | orchestrator | block-aware paragraph emission + form pairs |

| SCANNED_HANDWRITTEN | orchestrator | PaddleOCR + line-based form pairs |

| DOCX | `DocxExtractor` | python-docx, OOXML body in document order |

### Backend Protocols

OCR, layout analysis, and preprocessing are accessed via typed protocols defined in `ingest/interfaces/protocols.py`.

| Protocol | Default Implementation | Notes |
|----------|----------------------|-------|
| `OCRReader` | `PaddleOCRReader` (rapidocr-onnxruntime) | Lazy-loaded, cached per lang |
| `LayoutAnalyzer` | `YOLOLayoutAnalyzer` (yolo11n_doc_layout.pt — DocLayNet, MIT) | DocLayNet's 11 document classes map directly into womblex `ElementKind` via `_YOLO_DOCLAYNET_LABEL_MAP`. Inference imgsz follows a per-taxonomy default (DocLayNet 832, COCO 640) — the model card recommends 1280 for small-class recall (Caption / Footnote) but on this corpus 832 is empirically equivalent at ~3× the per-call speed; override to 1280 for document genres where small classes matter. Also consumed by `redact/stage.py` as exclusion regions on raster-fallback redaction detection — taxonomy-agnostic match on `block_type ∈ {figure, table}`. COCO `yolov8n.pt` retained as fallback if the DocLayNet checkpoint isn't resolvable. |
| `Preprocessor` | `preprocess_for_ocr()` | Deskew + histogram-gated binarisation |

## Preprocessing Pipeline

All OCR-dependent strategies run images through `preprocess_for_ocr()` before PaddleOCR:

| Step | Condition | Effect on FUNSD CER-s |
|------|-----------|-----------------------|
| Deskew | Skew angle > 0.5 deg, confidence > 0.3 | Neutral |
| Otsu binarise | `is_scanned` AND `is_bimodal` | +39% regression |
| Adaptive binarise | `is_scanned` AND NOT `is_bimodal` | Not observed in fixtures |
| Binarise skipped | NOT `is_scanned` AND `dynamic_range` > 0.1 | Baseline (best) |

## Metric Definitions

- **(raw)** = PaddleOCR on original image; **(pp)** = after preprocessing (deskew + binarise).
- **CER**: Levenshtein distance / reference length. 0.0 = perfect.
- **CER-s**: GT and OCR words spatially sorted by bounding-box centroid before CER. Isolates recognition from reading-order.
- **WER**: Word-level Levenshtein / reference word count.
- **Precision**: Predicted layout blocks matching a GT block with correct label (IoU >= 0.3).
- **Recall**: GT layout blocks matched by a prediction with correct label (IoU >= 0.3).
- **F1**: Harmonic mean of precision and recall.
- **Avg Confidence**: Mean per-region OCR confidence from RapidOCR (0–1).
