# Third-Party Data

This repository carries no third-party test data. The test suite reads only the
synthetic fixtures in [`fixtures/synthetic/`](fixtures/synthetic/README.md):
invented Australian-animal documents generated by a script in that directory
and released under this repository's licence. A bare clone runs every test that
does not need a paid API (Isaacus, AWS Bedrock) or a Postgres DSN.

Real-document test data is maintained in a separate repository:

- **Repository:** [DeepCivic/womblex-benchmark](https://github.com/DeepCivic/womblex-benchmark) (formerly `womblex-development-fixtures`)
- **Contents:** FUNSD form images, IAM handwriting lines, DocLayNet layout pages, womblex-collection documents
- **Purpose:** Scoring extraction against ground truth. Every `docs/accuracy/` report is produced there.

## Maintainer-only benchmark tests

`tests/test_bench_ocr_accuracy.py` scores OCR against FUNSD, IAM-line and
DocLayNet. It is marked `benchmark`, CI deselects it, and it skips unless the
benchmark fixture set is present at `fixtures/fixtures/` (git-ignored, never
committed). To run it, copy that set from a womblex-benchmark checkout:

```bash
cp -r ../womblex-benchmark/fixtures fixtures/fixtures
uv run python -m pytest -m benchmark -s -v tests/test_bench_ocr_accuracy.py
```
